1. 已实现
------------------------------------------------------------------------

  - BattleHudViewModel、HandViewModel、CardViewModel、CardPileViewModel。
  - BattleHUD 显示能量、手牌、抽牌堆数量和弃牌堆数量。
  - HandView 管理 CardView 集合、扇形布局、拖拽占位和出牌区域判定。
  - CardView 仅渲染 ViewModel，并把拖拽手势上报给 HandView。
  - BattlePresenter 把 PlayCardIntent 转为 BattleCommandApi 调用。
  - 命令和 Action 队列稳定后，BattlePresenter 使用最新状态刷新 HUD。
  - CardPileDialogModal 通过 Modal 栈只读展示抽牌堆或弃牌堆快照。
  - CardPileListView 使用 ScrollRect、GridLayoutGroup 和 ContentSizeFitter 管理滚动网格。
  - CardViewPrefab 顶层已迁移为 RectTransform，并显式绑定 CardView.root。
  - 缺失卡图时允许显示无图卡牌，不再强制读取不存在的图片。
