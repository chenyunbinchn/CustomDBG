1. 命名规则
------------------------------------------------------------------------

根 UI 使用“功能名 + UI 类型”，并以类型结尾：

  BattlePage
  BattleHUD
  CardPileDialogModal
  LoadingOverlay

内部组件不添加根 UI 类型后缀，例如 CardView、HandView、CardPileListView。
